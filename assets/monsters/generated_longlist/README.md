# Monster Longlist Generated Assets

Generated from `monster_generieren.md` as 13 sprite sheets. The images live in `sheets/`; `manifest.json` maps each `creature_*` slug to its sheet and grid cell.

The `cells/` directory contains one mechanically cropped PNG per slug. These crops are atlas cells, not hand-cleaned transparent sprites. Cells are ordered left-to-right, top-to-bottom. Duplicate source slugs were included once.
